💰 Personal Expense Tracker

📌 Project Description

Personal Expense Tracker is a Python-based application that helps users manage their daily expenses. It allows users to record, view, search, edit, and delete expenses while keeping track of total spending and category-wise expenses.

The application stores expense information in a JSON file so that the data can be loaded again when the program is restarted.

✨ Features

- ➕ Add new expenses
- 📋 View all recorded expenses
- 🔍 Search expenses by category
- ✏️ Edit existing expenses
- 🗑️ Delete expenses
- 💵 Calculate total spending
- 📊 View category-wise expense summaries
- 💾 Store expense data in a JSON file
- ✅ Validate user input

🛠️ Technologies Used

- Python
- JSON
- Object-Oriented Programming (OOP)

🚀 How to Run the Project

Prerequisites

- Python 3 installed on your computer
- A code editor such as VS Code

Steps

1. Clone this repository:
   
   git clone https://github.com/likitha2006b-tech/Personal-Expense-Tracker.git

2. Open the project folder in VS Code.

3. Run the Python program:
   
   python main.py

4. Follow the menu displayed in the terminal to manage your expenses.

📖 Application Menu

1. Add Expense
2. View Expenses
3. Search Expense
4. Edit Expense
5. Delete Expense
6. Calculate Total
7. Category Summary
8. Exit

🎯 Project Objective

The objective of this project is to provide a simple and convenient way to record daily expenses, monitor spending habits, and understand how money is spent across different categories.
